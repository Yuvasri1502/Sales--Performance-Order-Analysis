# 📊 Sales Performance & Order Analysis

## 📌 Project Overview

This project analyzes sales order data using Microsoft Excel to understand sales performance, order trends, product performance, customer distribution, and overall business performance.

An interactive Excel dashboard was created using Pivot Tables, Pivot Charts, calculated columns, and slicers.

## 🛠️ Tools & Technologies

- Microsoft Excel
- Power Query
- Pivot Tables
- Pivot Charts
- Slicers
- Excel Formulas
- Data Cleaning
- Data Analysis
- Dashboard Development

## 📂 Dataset

The dataset contains sales order information including:

- Order Number
- Quantity Ordered
- Price Each
- Order Date
- Status
- Product Line
- Product Code
- Customer Name
- City
- State
- Country
- Deal Size

## 📊 Key KPIs

The dashboard tracks important business metrics such as:

- Total Sales
- Total Orders
- Total Quantity
- Average Order Value
- Average Price

## 📈 Dashboard Analysis

The dashboard provides analysis of:

- Sales Performance
- Monthly Sales Trends
- Sales by Product Line
- Sales by Country
- Sales by Deal Size
- Order Performance
- Product Performance

## 🎛️ Interactive Features

The dashboard includes interactive slicers that allow users to filter and analyze the sales data dynamically.
